这份布局的设计思路

  • 5 个底部 tab：消息 / 首页 / 时光墙 / 纪念日 / 我的 —— 聊天从"角落按钮"升级成一级入口（主流做法）
  • 首页信息密度提升：天数大卡 → 最近重要日子（倒计时）→ 最近回忆横滑 —— 打开 App 一眼看完"我们的一切"
  • 消息页：会话列表 + 未读红点，点进气泡聊天（文字/图片/语音）
  • 时光墙：双列瀑布流，比现在的单列长列表更"相册"
  • 我的：个人信息 + 邀请码 + 设置分组，和竞品对齐
